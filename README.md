## What I'm Building

Two things I'm working on right now — both privacy-first, both solo.

### 🥗 ActiBite — AI-Native Health Tracker `[Beta]`

A full-featured nutrition and workout tracker I designed, built, and shipped entirely alone.

- **Barcode meal scanner** — `expo-camera` + Open Food Facts API with local SQLite cache; previously scanned products resolve instantly
- **Custom SVG data visualisations** — animated calorie rings, 7-day trend charts, macro progress bars; zero charting libraries
- **Adaptive AI layer** — learns from the user's actual intake and habits over time; adjusts calorie targets, macro splits, and workout plans; the app grows with the user instead of just logging for them
- **Versioned SQLite migration system** — atomic seed transactions, fresh install and live upgrade safe, no data loss
- **Zero backend** — all data lives on-device; no cloud, no account required to start

> Stack: `React Native` · `Expo SDK 55` · `TypeScript` · `expo-sqlite` · `expo-router` · `react-native-svg`

---

### ⌚ Guardian Band — Privacy-First Wearable `[Prototype]`

A wearable I'm building from scratch because every smart watch is a surveillance device with a good marketing team.

- **Brain:** ESP32-S3 (16MB flash, 8MB PSRAM) — WiFi-capable, standalone, no phone dependency
- **Display:** 1.54" E-Ink — always-on, readable in direct 45°C sun, near-zero static power draw
- **Sensors:** PPG (heart rate), GSR (stress), IR temperature (MLX90614)
- **Zero-knowledge protocol** — health data encrypted on-device before any Bluetooth transmission; server never holds the key; even a server breach exposes nothing
- **Companion app** in React Native — BLE data pipeline and health dashboard in development

> Stack: `ESP32-S3` · `C/Arduino` · `E-Ink` · `BLE` · `React Native` (companion)

## What I Care About

I got into health tech because I was frustrated. Every tracker I tried either had a terrible UX, a subscription paywall for basic features, or was quietly selling my data. ActiBite started as "I'll just build the thing I want" — and turned into a full product.

The Guardian Band is the same impulse applied to hardware. A wearable that does what you need, works without a subscription, and doesn't phone home.

I'm interested in the intersection of **mobile engineering**, **on-device AI**, and **privacy-preserving health data** — and I want to work on products that take all three seriously.
